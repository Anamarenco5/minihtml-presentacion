# Analizador MiniHTML · Presentación

Presentación web del Proyecto Integrador de **Lenguajes Formales y Autómatas** (UCC, 2026).

Contiene: lenguaje MiniHTML, alfabeto, gramática independiente de contexto, autómata finito con pila con simulador paso a paso, y el programa en C++ (`minihtml.cpp`) con su demo.

Es un sitio estático: un solo archivo `index.html`, sin compilación.

## Navegación
- Flechas ← → o barra espaciadora para cambiar de diapositiva.
